ScriptIX 2.6.1 packages: the scriptix command, with the basic checks inside.
Run as root. Nothing runs by itself after installing.

Debian, Ubuntu:                  dpkg -i scriptix_2.6.1-20261125.070524_all.deb
RHEL, Rocky, Alma, Oracle, SUSE: rpm -Uvh scriptix-2.6.1-20261125.070524.noarch.rpm
AIX 7.1 or newer, rpm:           rpm -Uvh scriptix-2.6.1-20261125.070524.aix6.1.noarch.rpm
AIX 7.1 or newer, installp:      sh scriptix-2.6.2520.425-aix.sh --install
AIX .bff file (smit, NIM):       sh scriptix-2.6.2520.425-aix.sh

On AIX use the rpm or the installp one, not both.
The .bff can only be made on AIX, so the -aix.sh file makes it there.

Scan with a SCAP file, as with oscap (needs perl; AIX and most Linux have it):
  scriptix content                 the SCAP files on this server
  scriptix info FILE.xml           what is inside, with the profiles
  scriptix eval --profile P FILE.xml --report report.html
  scriptix add FILE.xml --profile P    keep it as a check script

Or with the check scripts (needs only sh and awk):
  scriptix scan                    check this server (changes nothing)
  scriptix results                 what failed
  scriptix ssh root@OTHER          check another server over ssh, nothing to install there
  scriptix schedule daily 02:30    scan every day
  scriptix add FILE.sh             add a script made in ScriptIX
  scriptix help                    everything else

No SCAP file is inside. Copy one to the server, install the SCAP Security Guide there, or make
packages with your own scripts and SCAP file inside: ScriptIX, Script page, Packages...
The basic checks are a small set of our own, not a benchmark.
The packages are not signed. Compare SHA256SUMS.
The AIX files were never tested on a real AIX. Try them on a test server first.
